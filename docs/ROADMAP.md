# 開發規劃

進度追蹤請看 GitHub Issues 與專案看板；本檔記錄各階段的範圍。

## ✅ 第 1 階段：報名系統（已上線）
- 前台：賽事資訊、公告、項目報名人數
- 學校端：選手建檔與 Excel 匯入、報名矩陣即時檢核、列印報名表、送出鎖定
- 管理後台：報名總表、解鎖、CSV 匯出、賽事／項目／學校／帳號／公告管理
- Supabase 正式資料庫、邀請制帳號、設定密碼與忘記密碼

## 第 2 階段：賽務編排
- 選手號碼布自動編號（依學校代碼／組別）
- 預賽分組與道次編排（依報名成績或隨機，蛇形分配）
- 田賽試跳順序
- 秩序冊產生（可列印 PDF）
- 檢錄單、成績記錄表列印
- 報名時可填「最佳成績」作為分組依據

## 第 3 階段：成績彙整
- 成績登錄介面（徑賽計時、田賽多次試跳取最佳），適合手機、平板在場邊使用
- 預賽 → 決賽晉級計算（依名次＋成績遞補）
- 名次計算與同成績處理
- 大會紀錄維護與破紀錄自動標示
- 團體總錦標積分（積分表可設定）
- 前台即時成績公告
- 獎狀資料匯出（套印用）
- 成績異動紀錄（誰在什麼時候改了什麼）

## 第 4 階段：成績分析
- 個人歷年成績曲線（選手跨年度同一 ID）
- 各校獎牌數、積分、參賽人數
- 各項目成績分布與歷年趨勢
- 行政區比較
- 潛力選手名單（進步幅度、同年級排名）

## 第 5 階段：組訓
- 依成績篩選培訓名單／市代表隊
- 集訓梯次與日程
- 出缺席紀錄
- 定期體能、專項測驗成績追蹤
- 教練訓練日誌（新增 `coach` 角色）

## 基礎建設（隨時可做）
- 寄信服務改用自訂 SMTP（免費版內建寄信每小時上限很低，無法大量邀請學校）
- 教育局 OpenID 單一登入（需向教育局申請）
- 個資存放評估（若需國內主機，只需替換 `js/api.js` 的 supabase 實作）
